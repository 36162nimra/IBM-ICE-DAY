### High · PYSEC002 — Dynamic code execution via eval()

Source: atlas/security_examples.py:6 · Confidence: medium

eval() interprets a string as Python code. If that string can be influenced by untrusted input, arbitrary code may run.

Suggested remediation: Avoid dynamic evaluation. Use explicit parsing, a dispatch table, or a restricted data format.

```python

```

### High · PYSEC005 — SQL query assembled dynamically

Source: atlas/security_examples.py:11 · Confidence: medium

SQL-looking text is combined with a dynamic expression before execution. This can create injection risk if the value is untrusted; its origin cannot be proven statically.

Suggested remediation: Use parameterized queries for values. Allowlist identifiers that cannot be parameterized.
